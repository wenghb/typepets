Finger Training

Real touch-typing technique, one row at a time

Eight short stages take kids from the home row to the full keyboard. Color-coded keys and an on-screen hand guide show exactly which finger to use for every letter.

  • Spoken finger hints say which finger to use, in a natural recorded voice (three to choose from)
  • No-look mode hides the hints when they're ready, for bonus XP
  • Stars for accuracy, not raw speed
Bubble Pop

Type the word, pop the bubble

20 levels grow from home-row letters to short words, longer words, and whole phrases. Finishing training stages unlocks new levels, so the game always matches what kids have learned.

  • Kid-friendly pacing that ramps up gently as levels get harder
  • Tricky keys come back more often, so practice targets weak spots
  • Milestone rewards for the pet at levels 5, 10, 15, and 20
Your pet

A pet that grows only from real practice

Every session earns XP, and the pet evolves from an egg through six stages. Pets get hungry, and the only way to earn food is to practice. There's nothing to buy and no shortcuts.

  • Daily goal of a few minutes, with a streak freeze for off days
  • Six stages: Egg, Baby, Kid, Teen, Adult, Master
  • Nothing to buy: no shop, no coins, no upsells
Progress

Progress that parents and teachers can see

The Stats dashboard tracks streaks, practice time, speed, and accuracy over time. Speed only counts correctly typed characters while a child is actively typing, so a break never drags a score down.

  • Printable report with practice minutes, trends, and weakest keys
  • Certificates for finished stages, levels, and articles
  • Badges for milestones along the way

Frequently Asked Questions

Is TypePets really free?

Yes, 100% free. No signup, no premium tier, no ads, and no in-app purchases. Every feature is available right away. Grown-ups who find it useful can leave an optional tip.

Does TypePets collect my child's data?

No. Progress is saved in your browser's local storage on your own device. It is only uploaded if you choose to make a save code, and save codes never hold a name or contact details. There are no accounts, no ads, and no tracking cookies. We use Cloudflare Web Analytics, a privacy-first tool that doesn't use cookies or track individuals, to count page visits. The only thing ever sent to us is feedback you choose to send, with a short summary of progress levels and never a child's name. See our privacy policy.

What age is TypePets for?

TypePets is designed for kids ages 7–12 who are learning to touch type. Lessons start with just a few home-row keys, so younger beginners can keep up, and later stages and games give more confident typists a real challenge.

Can more than one child use TypePets on the same device?

Yes. Up to four kids can each have their own profile on the same browser, with their own pet, progress, and stats. Switch profiles inside the app. No emails or passwords are needed.

What happens to progress if we clear the browser or switch computers?

Progress is stored in the browser on that device, so clearing browsing data or moving to a different computer starts fresh. To keep it safe, get a save code on the Stats page: a short code like TIGER-427-MOON. Type it on the Home page of any computer to pick up where you left off; after that, progress saves to the code by itself. Prefer to keep a copy yourself? Download a Pet Passport backup file instead.

Does TypePets work on Chromebooks?

Yes. TypePets runs in Chrome with nothing to install, so it works on home and school Chromebooks. Chromebook keyboards have a Search or Launcher key where Caps Lock usually is and a row of shortcut keys instead of F1–F12, which doesn't get in the way of letter practice. If a school Chromebook clears data when students sign out, use a Pet Passport code to carry progress between sessions. More in our Chromebook typing guide.

Can I use TypePets on an iPad or tablet?

Yes. TypePets works on iPads and other tablets: tap the typing area to bring up the on-screen keyboard. For learning touch typing, a physical keyboard is best (a keyboard case or an inexpensive Bluetooth keyboard works well), because kids need to feel the keys and the bumps on F and J.

Is there a report for parents or teachers?

Yes. The Stats dashboard shows speed and accuracy over time, which keys are trickiest, and badges earned. You can also print a one-page progress report with practice minutes, speed and accuracy trends, weakest keys, and completed lessons, plus certificates for finished training stages, Bubble Pop levels, and articles.

Do students need accounts to use TypePets in class?

No. There are no student accounts and TypePets never collects student names, so there is nothing to roster. Students on shared Chromebooks can carry their progress with a save code, which holds typing progress only. Teachers can share a classroom link that opens a specific lesson with a timer, for example https://typepets.com/pages/training.html?stage=1&min=10 opens Stage 1 with a 10-minute countdown. See For teachers to build one.

Which keyboard layouts and languages does TypePets support?

For now, TypePets supports the QWERTY keyboard layout and English practice text only. Other layouts such as AZERTY, QWERTZ, or Dvorak, and other languages, aren't supported yet.

How does the pet system work?

Every practice session earns XP. Your pet starts as an egg and evolves through 6 stages: Egg, Baby, Kid, Teen, Adult, and Master. Pets also get hungry, and the food to feed them is earned by practicing, so the pet only grows when your child actually types. There is nothing to buy.

How long should my child practice each day?

10–15 minutes a day is plenty for most kids aged 7–12. Short daily sessions build muscle memory faster than one long session a week. You can set a daily goal in the app, and a streak freeze keeps one off day from breaking a streak. See typing goals by grade for realistic targets.
